# Сервер

## Минимум

- VPS с Ubuntu 22.04/24.04, 1 CPU / 1 ГБ достаточно
- свободные порты **80** (сертификат) и **443**
- домен, A-запись которого смотрит на сервер (для панели и подписок)

## Раскладка портов

| Порт | Что | Кому |
|---|---|---|
| 443 | VLESS + REALITY | клиенты (телефон, чужие сети) |
| 8443 | Shadowsocks-2022 | Mac за туннелем Happ |
| 1001 | панель 3x-ui | только вам |
| 2096 | сервер подписок | ссылки для клиентов |

443 отдан REALITY сознательно: нестандартные порты в РФ блокируют охотнее, а REALITY —
самый живучий протокол из доступных.

## Установка узла

```bash
scp server/install-sg-server.sh root@SERVER_IP:/root/
ssh root@SERVER_IP 'bash /root/install-sg-server.sh'
```

Скрипт:

1. ставит sing-box;
2. генерирует REALITY-ключи и UUID;
3. пишет `/etc/sing-box/config.json` и systemd-юнит;
4. открывает порт в ufw;
5. печатает готовый `outbound` для клиента.

## Панель 3x-ui (по желанию)

```bash
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
```

Даёт веб-интерфейс, подписки, лимиты и несколько inbound'ов на одном сервере.

**Обязательно после установки:**

1. сменить порт панели на нестандартный;
2. поставить TLS (Let's Encrypt) и открывать только по https;
3. закрыть порт панели файрволом для всех, кроме себя, или ходить через
   `ssh -L 1001:127.0.0.1:1001 root@SERVER_IP`.

## Подписки

3x-ui умеет отдавать ссылку-подписку на клиента:

```
https://YOUR_DOMAIN:2096/<subPath>/<subId>
```

Клиент (Happ, v2rayNG, Hiddify, Shadowrocket) сам разберёт base64 и покажет протоколы.
Порт в ссылке — плата за то, что 443 занят REALITY.

## Автопродление сертификата

```bash
certbot certonly --standalone -d panel.example.com
```

и хук `/etc/letsencrypt/renewal-hooks/deploy/`, который копирует сертификат туда, где его
ждёт панель, и перезапускает её.
